# TR23 三角形

> [!info] 出处
> 《Trading Price Action Trading Ranges》第 23 章 *Triangles*，英文 PDF 第 448–452 页。
> 配图：`chats/TPA-Trading Ranges/TPA-Trading-Ranges-c23`
> 上一篇：[[TR22 窄幅交易区间]] · 下一篇：[[TR24 剥头皮、波段、交易与投资]] · 阶段：[[00 周计划#阶段 4]] · 术语：[[00 核心术语中英对照表]]

> [!abstract] 一句话总结
> 三角形（triangle）就是有三推的交易区间，处于突破模式（breakout mode）；上升、下降、对称三角形交易含义相同，不必区分：通常等突破再交易，突破常失败并测试另一侧，成功则走出约等于三角形高度的测量移动；三推的区间常出现在趋势后期，成为最终旗形（final flag）。

## 核心观点

1. **三角形是区间也是通道，处于突破模式**：价格被两条线夹住，所以是区间、也是通道（channel）；称为三角形的最低要求是有三推向上或向下。因为有更高低点或更低高点（扩张三角形两者都有），也带有趋势性。楔形（wedge）是上升或下降的三角形：坡度很小时叫三角形，坡度大时叫楔形；楔形常作为旗形（延续）或趋势末端的反转形态，所以放在旗形和反转部分讲。各种三角形的几何定义：扩张三角形（expanding triangle）夹在两条发散线之间，两条都是趋势通道线（上线在更高高点之上、下线在更低低点之下）；oo（外包-外包，一根外包K后跟更大的外包K）是小扩张三角形；收敛三角形夹在两条趋势线之间，因为市场同时处于小熊趋势和小牛趋势；ii 通常是更小周期上的小三角形；上升三角形上方是阻力线、下方是牛趋势线，下降三角形下方是支撑线、上方是熊趋势线；楔形是趋势线与趋势通道线收敛的上升或下降通道。所有三角形至少一个方向三段、另一方向两段；任何三段、横向或倾斜、形似楔形的形态都是三角形。和可以无限延伸的通道、区间不同，三角形处于突破模式，突破即将到来；突破可强可弱，可能有跟进成为趋势、可能失败反转，也可能横走演变成更大的区间。（p.448）
2. **突破方向：通常顺前一段趋势**：三角形是趋势中的停顿，牛趋势中的三角形通常向上突破，熊三角形通常向下。楔形更复杂：下降楔形（bear wedge）像所有熊通道一样是牛旗。如果一个大下降楔形占满整个屏幕，屏幕上的K线就是熊趋势，向上突破是逆屏幕趋势的反转；但屏幕左边有没有大牛趋势无关紧要，任何下降楔形都会表现得像牛趋势中的大回调，也就是牛旗，向上突破虽然是反转，却是"预期方向"，多数在更高周期上本来就是牛旗。（p.449）
3. **三推 = 更强的逆势压力，常成为最终旗形**：每个有三推的区间在功能上都等同于三角形，形状不清晰也应当作完美三角形来交易。它比一推回调（高1/低1）和两推回调（高2/低2）更复杂，代表更强的逆势压力；逆势方越来越强，所以这类形态多出现在趋势和波段后期，常成为最终旗形。三角形超过三推时，多数交易者开始称它为交易区间。（p.449）
4. **倾斜三推不一定是楔形反转**：倾斜的三推形态，很多人误当楔形去做反转。但如果三推处在窄通道里，它通常像通道一样无限延续，而不会像楔形那样反转；有三推本身并不是反向交易的理由。不确定楔形会不会反转时，不要在突破时入场：例如较陡的下降通道，趋势线和通道线收敛但离得很近，不要买第一次向上反转或楔形的向上突破，等突破发生后评估强度。强突破（特征见第 2 章）就等回调，在回调结束时买（突破回调买入）；如果几根K都没有回调，市场正在形成强牛急速，多数人眼里已几乎肯定总在场内做多，可以像其他强突破一样交易：买K线收盘、在前一根K高点上方买、用限价单买任何小回调，或等回调。（p.449–450）
5. **水平三角形：多空平衡，突破走不远；三种三角形一视同仁**：多数三角形较水平，说明多空都认为这个价位有价值，所以突破常走不远就反转回区间，三角形也常是趋势的最终旗形。突破失败时，价格通常被拉回区间，有时从另一侧突破，形成两段修正甚至趋势反转。上升、下降、对称三角形含义相同，不必区分，都可叫三角形，都大致水平。它们略微更常顺前一段趋势突破，但不足以单凭这点下单；每个都是不确定区域，最好等突破再交易。形态够高时，可以像区间一样淡化两端，在底部附近买、顶部附近卖。突破常失败，和任何通道一样，反转回通道后通常测试另一侧；任一方向突破，通常走出约等于通道高度的测量移动，走得更远则市场可能进入趋势。（p.450）
6. **扩张三角形会"翻转"**：它可以是趋势末端的反转形态，也可以是趋势中的延续形态。突破后常失败并反转，从另一侧突破，形成更大的扩张三角形，于是反转形态变成延续形态、延续形态变成反转形态。例如熊趋势底部的扩张三角形是反转形态，向上突破顶部后常失败转跌，结果成为一个大的扩张三角形熊旗。有时能引出主要反转，但通常更像区间、演变成其他形态（第三本书趋势反转章节详述）。（p.450）

## 关键概念

| 英文 | 中文 | 本章中的含义 |
| --- | --- | --- |
| triangle | 三角形 | 至少三推的区间；处于突破模式 |
| breakout mode | 突破模式 | 三角形里突破即将出现，方向不确定 |
| expanding triangle | 扩张三角形 | 两条发散的趋势通道线；突破常失败并翻转成反向形态 |
| contracting / symmetrical triangle | 收敛/对称三角形 | 夹在两条趋势线之间，市场同时处于小牛和小熊趋势 |
| ascending / descending triangle | 上升/下降三角形 | 上方阻力线+下方牛趋势线 / 下方支撑线+上方熊趋势线；交易含义与对称三角形相同 |
| wedge | 楔形 | 倾斜的三角形，趋势线与通道线收敛；下降楔形是牛旗 |
| ii / oo | 连续内包 / 连续外包 | ii 是小周期上的小三角形；oo 是小扩张三角形 |
| three pushes | 三推 | 三推的区间功能上等同三角形，逆势压力强于高1/高2 |
| final flag | 最终旗形 | 三角形多出现在趋势后期，常成为最终旗形 |
| breakout pullback | 突破回调 | 楔形强突破后等回调再进；图 23.1 中 K线 26、K线 23 |
| measured move | 测量移动 | 三角形突破后通常走出约等于其高度的距离 |
| tight trading range | 窄幅交易区间 | 上升楔形向上突破后横走演变成窄幅区间，是多头强势信号 |

## 规则与可操作要点

**识别**

- [ ] 数推动：至少三推向上或向下？有就当三角形看，不管形状是否标准。（p.448–449）
- [ ] 超过三推（或五推）：改称交易区间，按区间处理。（p.449、p.451）
- [ ] 三角形之前的趋势方向是什么？它在趋势后期吗？→ 警惕成为最终旗形。（p.449–450）

**交易水平三角形**

- 默认：等突破再交易，不因"三角形略偏顺势突破"就提前入场。（p.450）
- 够高时：在下边线（牛趋势线）测试处买、上边线（熊趋势线）测试处卖，像区间一样淡化两端。（p.450、p.452）
- 突破失败回到形态内：预期测试另一侧，可能从另一侧突破。（p.450）
- 突破成功：目标约等于三角形高度的测量移动；超过它则可能已成趋势。（p.450）

**交易倾斜三推（楔形）**

- 三推在窄通道里 → 当通道看，不做反转。（p.449）
- 不确定是否反转 → 不买第一次反转、不追楔形突破；等突破出现再评估。（p.449）
- 强突破 → 等回调结束时买（突破回调）；几根K都不回调 → 视为总在场内做多，可买收盘、前一根高点上方、或限价买小回调。（p.449–450）

**扩张三角形**

- 顶部的扩张三角形可在第三推高点做空（图 23.2 C 的 K线 3）；它常演变成扩张三角形底部，于是在第三推低点之上买。（p.452）

> [!question] 先自己判断
> 1. INTC 日线上的三角形 A 是什么？突破后没有下跌而是横走，说明什么？
> 2. 三角形 B 和 E 是同一类三角形吗？它们的突破结果分别怎样？
> 3. 三角形 C 是什么三角形？可以在哪里做空、又在哪里做多？
> 4. 三角形 D 该怎么交易？

> [!success]- Brooks 的解读（点开查看）
> 1. 三角形 A 是上升楔形，突破没有动能，形态演变成窄幅区间。上涨中的上升楔形向下突破后不跌而横走，是强势信号，多头很可能回来：空头在牛趋势中看到上升楔形却无法让市场反转，很快会回补空单、暂停做空，市场变成单边，向上突破一直走到空头愿意再空、多头愿意卖出部分或全部多单止盈的价位。（p.452）
> 2. 都是下降三角形。B 向上突破；E 先向上突破失败，然后向下突破，又失败了。（p.452）
> 3. C 是扩张三角形，交易者可以在 K线 3 高点做空。扩张三角形顶部通常演变成扩张三角形底部，反之亦然，这次也一样，于是可以在 K线 3 低点上方买。（p.452）
> 4. D 是不完美的对称三角形。对称三角形就是交易区间，可以在测试下方牛趋势线时买、测试上方熊趋势线时卖。三角形很少完美。（p.452）

## 实盘应用

1. **数推，而不是看形状**：MES/MNQ 5 分钟图上每出现一段横盘，就在截图上把高点和低点各标 1、2、3；凑满三推就写"三角形 / 突破模式"，同时写下之前的趋势方向和"可能是最终旗形吗"。
2. **ii 当作小三角形处理**：每次出现 ii，切到 1 分钟图看它是不是三角形，记录 ii 突破后的跟进情况和失败率。
3. **三角形突破后量高度**：突破时画出三角形高度的测量移动目标，统计实际走到目标的比例，以及突破失败后测试另一侧的比例。
4. **楔形突破后"先评估、后入场"**：遇到陡峭下降通道里的三推，强制自己不买第一次反转；等向上突破K收盘，判断强弱，强就等回调买，记录这样做与直接买楔形突破的结果差异。
5. **扩张三角形的翻转**：遇到扩张三角形，记录它第一次突破后是否失败并翻成反向的更大扩张三角形。

## 易错点

- **看见三推就做反转**：倾斜三推如果在窄通道里，会像通道一样延续，而不会像楔形那样反转；有三推本身不是反向交易的理由。（p.449）
- **因为"上升三角形偏多"提前下单**：上升、下降、对称三角形含义相同，只是略偏顺势突破，不足以作为下单依据，要等突破。（p.450）
- **把三角形突破当成趋势开始**：多数三角形水平、多空平衡，突破常走不远就回到区间，三角形还常是最终旗形。（p.450）
- **执着于画出"完美"三角形**：三角形很少完美，有很多种画法，叫什么不重要，按区间行为来交易。（p.451–452）

> [!note] 笔者注
> 第 449 页说三角形"超过三推"多数人改称交易区间，第 451 页又说"超过五推"才不再叫三角形。两处数字不同，但结论一致：推数多了就按普通区间对待。

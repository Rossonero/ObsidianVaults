# T-P2 第二部分 趋势线与通道

> [!info] 出处
> 《Trading Price Action Trends》Part II *Part II: Trend Lines and Channels*，英文 PDF 第 223–226 页。
> 配图：`chats/TPA-Trends/TPA-Trends-part02`
> 上一篇：[[T12 形态演变]] · 下一篇：[[T13 趋势线]] · 阶段：[[00 周计划#阶段 2]] · 术语：[[00 核心术语中英对照表]]

> [!abstract] 一句话总结
> 趋势线（trend line）和趋势通道线（trend channel line）都是框住价格的直线，但在价格的两侧：牛趋势里趋势线在低点下方、通道线在高点上方，熊趋势相反。趋势线主要用来找顺势交易，通道线主要用来找可交易的逆势交易；横向通道就是交易区间，上沿是阻力、下沿是支撑。

## 核心观点

1. **区分线的子类型**：很多交易者把所有线都叫趋势线，但区分几种子类型更有帮助。趋势线和趋势通道线都是框住价格行为的斜直线，位于价格两侧，合起来构成通道（channel）。牛趋势中趋势线在低点下方、通道线在高点上方；熊趋势中趋势线在高点上方、通道线在低点下方。（p.223）
2. **两条线的关系决定形态**：构成通道的两条线最常是平行或大致平行；在楔形和多数三角形中是收敛的；在扩张三角形中是发散的。（p.223）
3. **两种线的用途不同**：趋势线最常给出顺势交易的形态，趋势通道线最有助于找到可交易的逆势交易。曲线和通道带（bands）太主观，在需要快速下单时要想太多，不用。（p.223）
4. **横向通道 = 交易区间**：通道可以向上、向下或横向。横向时线是水平的，上方是阻力线（resistance line），下方是支撑线（support line）。（p.223）
5. **阻力不等于派发、支撑不等于吸筹**：有些股票交易者把阻力线看作派发区（多头出场），把支撑线看作吸筹区（多头加仓）。但现在机构做空和买入一样多，阻力线可能是机构新开空单的地方，也可能是多头出场的地方，两者可能性相当；支撑线可能是空头出场的地方，也可能是新开多单的地方。（p.223）
6. **扩张时没有趋势线；对称三角形里没有通道线**：通道在扩张，就没有趋势，因此没有趋势线，只有上下两条通道线。对称三角形是收敛通道，里面同时有一个小熊趋势和一个小牛趋势，所以由两条趋势线构成、没有通道线。收敛三角形可以分成对称、上升、下降三种，但交易方式都一样，这些名称没必要。（p.224）

## 关键概念

| 英文 | 中文 | 本章中的含义 |
| --- | --- | --- |
| trend line | 趋势线 | 牛趋势在低点下方、熊趋势在高点上方的斜线；主要用于顺势交易 |
| trend channel line | 趋势通道线 | 与趋势线位于价格另一侧、斜率相近；主要用于逆势交易 |
| channel | 通道 | 两条线框住的价格区域，可向上、向下或横向 |
| resistance line | 阻力线 | 横向通道（交易区间）的上沿 |
| support line | 支撑线 | 横向通道（交易区间）的下沿 |
| wedge | 楔形 | 收敛且倾斜的通道，如图 PII.1 线 3 与线 4 |
| expanding triangle | 扩张三角形 | 两条线发散；没有趋势，因此没有趋势线 |
| symmetrical triangle | 对称三角形 | 收敛通道，由两条趋势线构成，没有通道线 |
| distribution / accumulation | 派发 / 吸筹 | 传统说法；Brooks 认为机构在阻力处新开空单的可能性与派发一样大 |
| breakout mode | 突破模式 | 开盘小区间时在区间上下 1 tick 各挂止损单 |
| measured move | 测量移动 | 突破扩张三角形后的最小目标 = 三角形高度 |

## 规则与可操作要点

这是 Part 导论，以判断清单为主：

- [ ] 先判断当前通道方向：向上、向下还是横向？横向就按交易区间处理，上沿阻力、下沿支撑。（p.223）
- [ ] 分清你画的是哪条线：牛趋势里低点下方的是趋势线（找回调买点），高点上方的是通道线（找过冲反转的逆势机会）；熊趋势相反。（p.223）
- [ ] 两条线是平行、收敛还是发散？收敛且倾斜 → 楔形；收敛且两边都是趋势线 → 三角形；发散 → 扩张三角形，没有趋势线。（p.223–224）
- [ ] 不用曲线和通道带，只画直线。（p.223）
- [ ] 不要先入为主地认为阻力处只有多头出场、支撑处只有多头买入；两边都可能是机构新开仓。（p.223）
- 开盘小区间突破模式：开盘区间上方 1 tick 挂买入止损单、下方 1 tick 挂卖出止损单；突破扩张三角形的最小目标是三角形高度的测量移动。（p.225）

## 实盘应用

1. **每天开盘前画两条线**：在 MES/MNQ 5 分钟图上，按昨天最后一段走势画出趋势线和趋势通道线，并在旁边标注"顺势用"/"逆势用"，开盘后看价格碰到哪条线、出现什么信号。
2. **给通道分类**：每次画出一对线，记下它是平行、收敛还是发散，对应通道/楔形/三角形/扩张三角形，练习快速归类。
3. **只用直线**：把图表上的布林带等通道带指标关掉一周，只用直线判断支撑阻力，记录这样做是否让决策更快。
4. **阻力处双向思考**：价格碰到区间上沿时，同时写下"多头出场"和"空头新开仓"两种可能，再看随后的K线是哪一种。

## 易错点

- **把所有线都叫趋势线**：趋势线和通道线位于价格两侧、用途相反，混用会把顺势和逆势的入场搞反。（p.223）
- **用曲线和通道带**：太主观，快速下单时要想太多。（p.223）
- **把阻力只看成派发、支撑只看成吸筹**：机构在阻力处新开空单、在支撑处平空的可能性一样大。（p.223）
- **在扩张三角形里硬画趋势线**：通道在扩张就没有趋势，只有两条通道线。（p.224）
